ご利用ガイド（お客様マイページ）

重要
予約ごとに自動生成される「1予約＝1URL」のお客様ページ。傷チェックの確認＋貸渡約款の同意を、タブレットで見せながらサインをもらう仕組み。日本語/英語/繁体字/韓国語に対応。
場所：予約が入ると自動生成／一覧＝データタブ「🪪ご利用ガイド一覧」
  1. お客様来店時、その予約のご利用ガイドを開く（データタブの一覧、またはOPシートから）
  2. タブレットで見せながら ①傷チェックの承認サイン をもらう
  3. 続けて ②貸渡約款の同意サイン をもらう
  4. 2つ揃うと 締結完了。サイン後はロック＝閲覧専用（共有しても書き換え不可）
  5. 同じURLをお客様に送れば、後からいつでも見返せる
🔒 サインは予約番号に紐づいて永久保存（台帳にも記録）。予約を消しても記録は残ります。外車/特殊車は「基本操作ガイド」も自動で表示されます。
📧

OPシート「ガイド送信」タブ

新機能
締結が終わった予約のご利用ガイドURLを、お客様へメール送信するタブ。当面はスタッフがボタンから手動送信します。
場所：OPシート → 上部タブ「📧ガイド送信」
  1. OPシートを開き、上部タブの 📧ガイド送信 を選ぶ
  2. 本日の引渡し予約が一覧表示。上部に 🔒未締結 N件 / ✅締結済 N件
  3. 締結済（サイン2つ完了）の予約だけ 📧メール送信 ボタンが出る → 押すとメーラーが開く（宛先・本文・URL 自動入力）→ 送信
  4. 未締結は 🔒締結後に送信可（黄色カードで上に表示）＝先にサインを取得
  5. メール未登録の予約は 🚩メール未登録（送れないので電話等で対応）
🔗「URLコピー」「開く」はスタッフ用（サイン取得・内容確認に使えます）。問題なければ将来締結完了→自動送信にします。

傷チェック

車両の傷・へこみを図面上に記録。貸出前の状態をお客様とマイページ上で共有し、返却時の新規傷を防ぎます。
場所：傷チェックアプリ（車両別）／マイページ内に埋め込み表示
  1. 貸出前に対象車両の傷チェックで現在の状態を登録（写真・マーカー）
  2. ご利用ガイド（マイページ）にその車両の傷図が自動表示される
  3. お客様に確認いただき「①傷承認サイン」をもらう
  4. 返却時に新しい傷がないか照合
📁

予約取込（CSV）

OTA（じゃらん/楽天/スカイチケット/エアトリ等）の予約CSVを取り込み、予約データに登録します。※メール自動取込が動いていれば手動取込は不要。
場所：メニュー「📁CSV」タブ
  1. 各OTAの予約CSVをダウンロード
  2. 「📁CSV」タブでファイルを読み込む
  3. 取り込まれた予約は自動で配車・OPシート・マイページが生成される
🚗

配車（配車表）

予約に実車を紐付け。配車するとマイページの車両名・傷チェックも自動で反映されます。
場所：メニュー「🚗配車」タブ
  1. 配車表で予約の車両セルをタップ
  2. 空いている車両を選んで割り当て（重複・メンテ車はガードで弾かれる）
  3. 配車すると傷チェック・マイページに車両が反映される
📋

OPシート（当日オペレーション）

その日の引渡し（DEL）・回収（COL）・洗車・送迎などの作業一覧。担当・時間・場所を管理。
場所：メニュー「🚗配車」→ OPシート、または各所の OPボタン
  1. 上部の日付タブで当日を選ぶ
  2. タブ（サマリー/DEL・COL/洗車/来店/マスター/📧ガイド送信）で切替
  3. 担当・時間・場所を入力（手入力は保護されます）
💳

決済・請求

じゃらん事前決済の状況確認、Square請求リンクの発行・入金確認など。
場所：メニュー「💳決済」タブ ／ 会計「🧾」タブ
  1. 「💳決済」で事前決済の入金状況を確認
  2. 請求が必要な予約はSquareリンクを発行
  3. 入金は自動反映（会計タブで確認）
