# 市場価格（一般小売の相場）の判断基準

オーナー指示（2026-10-31）：定義をあいまいにしないため、相場をどの基準で取っているかをここと画面（車両カルテの「📊 市場価格」→「この基準で検索しています」）に残す。プロの査定ではなく、あくまで目安。基準を足すときは `vehicle-life.js` の `MARKET_RULE` とこのファイルを同じ内容で直す。

| 項目 | 基準 |
|---|---|
| 車種 | カーセンサーの同じ車種（車種コード、例 アクア＝TO_S228）。クラスは車種で決まる |
| 年式 | その車の年式 ±1年（例：2017年式なら2016〜2018年式） |
| 走行距離 | 売る時点の走行を1万km単位に丸めて ±1万km（例：6.4万kmなら5〜7万km。カーセンサーの指定が1万km刻みのため。オーナー承認 2026-10-31） |
| 必須条件 | 排気量・動力（ハイブリッド／ガソリン／ディーゼル）・駆動方式（2WD／4WD）・乗車定員（何人乗り）の4つは必ず合わせる（同じ車種でも価格帯が別になるため、オーナー指示 2026-10-31） |
| 修復歴 | 修復歴ありは除く |
| 台数が少ない時 | 5台未満なら、年式を±2年 → 走行も±2万kmの順に広げ、5台以上になった条件で出す（広げた時は画面に明記。オーナー決定 2026-10-31）。それでも5台未満なら参考値、0台なら該当なし |
| グレード・装備 | 絞らない。装備は記録だけ |
| 派生モデル | クロスオーバーなど価格帯が別の派生モデルは、派生モデルだけで取る |
| 出し方 | 本体価格（支払総額ではない。オーナー承認 2026-10-31）の中央値と、真ん中50%（25〜75%）の価格帯。店の売り出し価格で、売れた価格ではない。毎週ブラウザで調査 |
| 数え方 | 本体価格の安い順に並べ、25%・50%・75%の順位の台が載るページだけ開く（1ページ30台。例：318台なら80・159・239番目＝3・6・8ページ目＋台数を見る1ページ目）。全部のページは見なくても順位で決まる |
| 買取見込み | 小売相場の中央値 × 設定の％（初期75%） |

## グレードで絞らない理由（2026-10-30 実測）

アクア 2016〜2018年式・6〜8万km・修復歴なし、64台。

| 範囲 | 台数 | 中央値 | 真ん中50%の価格帯 |
|---|---|---|---|
| 全グレード | 64 | 94.4万 | 85.0〜102.4万（幅17万） |
| G | 9 | 86.0万 | 78.0〜94.4万（幅17万） |
| S | 24 | 95.8万 | 82.9〜103.2万（幅20万） |
| S スタイルブラック | 18 | 91.5万 | 88.4〜100.2万（幅12万） |
| クロスオーバー | 6 | 118.1万 | 103.2〜128.7万 |

普通のグレード同士では絞っても価格帯はほとんど狭くならず、台数が減って週ごとの中央値がブレやすくなる。派生モデル（クロスオーバー）だけは価格帯が別なので分ける。ほかの車種も、調査を始めるときに同じ比べ方で確かめる。

## 動力・駆動を必須にする理由（2026-10-31 実測、オーナー指摘）

アルファード 2017〜2019年式・6〜8万km・修復歴なし（370台中33台を確認）。

| 範囲 | 台数 | 中央値 | 真ん中50%の価格帯 |
|---|---|---|---|
| 全部まとめて | 33 | 296万 | 259〜345万 |
| 2.5 ガソリン 2WD | 25 | 289万 | 257〜322万 |
| ハイブリッド E-Four（4WD） | 4 | 349万 | 304〜366万 |

ハイブリッド4WDは中央値で約60万円高い。動力と駆動をまぜると相場が引っ張られるので、最低限の条件として必ず合わせる。駆動方式は車両マスターにまだ無いので入力が必要（型式からも判別できる）。
